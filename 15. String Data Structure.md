# Strings

A string is a sequence data structure used to `store text or characters`

In Python, strings are represented using:

- single quotes ' '
- double quotes " "
- triple quotes ''' ''' or """ """

**Examples**
``` python
name = "Python"

city = 'Delhi'

message = """Hello
World"""
```
---
## Why String is a Data Structure?

Because a string stores multiple characters in order

Example:
`word = "HELLO"`

| Index | Character |
| ----- | --------- |
| 0     | H         |
| 1     | E         |
| 2     | L         |
| 3     | L         |
| 4     | O         |

So string behaves like a sequence (array) of characters

---
## Characteristics of String

#### 🔹 **1) Ordered**

Characters maintain order.
``` python
word = "CAT"
```
C comes before A and A before T.

#### 🔹 **2)Immutable**

Strings cannot be changed after creation.
``` python
word = "Python"

word[0] = "J"
```
Gives:
TypeError

#### 🔹 **3)Indexed**

Each character has an index.

#### 🔹 **4)Iterable**

Can loop through string.

``` python
for ch in "ABC":
    print(ch)
```
Output:
``` text
A
B
C
```

## String Indexing

Index means position of character

🔹 **1) Positive Indexing**
``` python
word = "PYTHON"
```
| P | Y | T | H | O | N |
| - | - | - | - | - | - |
| 0 | 1 | 2 | 3 | 4 | 5 |

🔹 **2) Negetive Indexing**
``` python
word = "PYTHON"
```
| P  | Y  | T  | H  | O  | N  |
| -- | -- | -- | -- | -- | -- |
| -6 | -5 | -4 | -3 | -2 | -1 |

Example:-
```python
word = "PYTHON"

print(word[0])  #P
print(word[-1]) #N
```

---

## String Slicing

Slicing extracts part of string.

🔹 Syntax
`string[start:end:step]`

Examples:

```python
word = "PYTHON"

print(word[1:4])  #YTH  start = 1 and end = 4 (excluded)
print(word[:3])   #PYT
print(word[2:])   #THON
print(word[::-1]) #NOHTYP
```

---
## String Operations

🔹 **1) Concatenation**

Joining strings using +
```python
a = "Hello"
b = "World"

print(a + b)   #HelloWorld
print(a+' '+b) #Hello World
```

🔹 **2) Repetition**
```python
print("Hi" * 3) #HiHiHi
```

🔹 **3) Membership Operator**

Checks existence.
```python
print("P" in "PYTHON")      #True
print("P" not in "PYTHON")  #False
```

Looping Through String:
```python
word = "DOG"

for ch in word:
    print(ch)
```
Output:
```
D
O
G
```
