# Python Data Types

Data Types represents what kind of value a variable is storing.

## Main Built-in Data types in Python
### 1️⃣Numeric Types
Used to store numbers
| Type | Example|
|------|--------|
|int   | 10 , -9 , 0|
|float|2.3 , -3.2|

### 2️⃣Text Type
Used to store text
| Type | Example|
|------|--------|
|str   | " ", "Python"|

### 3️⃣Sequence Type
Used to store multiple Value
| Type | Example|Ordered|Changeble|
|------|--------|-------|---------|
|list   | [ 1 , 2 , 'a'], | Yes | Yes |
|tuple   | ( 1 , 2 ), | Yes | No |
|range   | range(3), | Yes | No |

### 4️⃣Mapping Type
Used to store key–value pairs.
| Type | Example|
|------|--------|
|dict   | { "language":"Python" , "file":"demo.py" }|

### 5️⃣Set Type
Used to store unique values
| Type | Example|
|------|--------|
|set   | { 1 ,2 , 3 }|

### 6️⃣Boolean Type
Used for True or False
| Type | Example|
|------|--------|
|bool   |True,False|

### 7️⃣ None Type
Represents no Value
| Type | Example|
|------|--------|
|NoneType   |None|

## How to check the Data Type
We can check the Data type using built-in-function called type()
type is a built-in function in Python that tells you what kind of data an object is.
```python
print(type(3.14))        # <class 'float'>
print(type("Python"))    # <class 'str'>
print(type([1, 2, 3]))   # <class 'list'>
print(type((1, 2)))      # <class 'tuple'>
print(type({"a": 1}))    # <class 'dict'>
print(type(True))        # <class 'bool'>
print(type(None))        # <class 'NoneType'>
```

We can also check the Data type using another built-in-function called isinstance()
isinstance() is a built-in function used to check whether a value belongs to a specific data type
```python
isinstance(3.5, float)        # True
isinstance("Hi", str)         # True
isinstance([1,2], list)       # True
isinstance(True, bool)        # True
```
