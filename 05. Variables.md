# Variables in Python

- A Variable is a name that is assigned a value.
- The type of the variables is inferred based on its value. They do not require explicit declaration of the type.

### Rules for Naming Variables
To use variables effectively, we must follow Python’s naming rules:

- Variable names can only contain letters, digits and underscores (_).
- A variable name cannot start with a digit.
- Variable names are case-sensitive like **name** and **Name** are different.
- Avoid using Python keywords as variable names.

Below listed are the valid variable names:-
```python
World100=10
_name='sahana'
Total_percentage=25
```

Below listed are the invalid variable names:-
```python
100World=10
for='sahana'
Total-percentage=25
```
### Dynamic Typing
In Python, same variable can hold different values during execution. This is called Dynamic Typing
```python
x = 5
x ='sahana'
```
## Assigning Values to Variables
In Python the values can be assigned to varibles in 2 ways
- Basic Assignment:-
  
  Varibles are assigned values using **=** operator
  ```python
  World100 = 10
  _name = 'sahana'
  Total_percentage = 25
  ```
- Multiple Assignment:-
    - Assigning Same Value:-
      
      Same Value is assigned the different Variables in a single line
      ```python
      x,y,z = 20
      print(x,y,z)
      ```
      Output:-
      ```text
      20 20 20
      ```
      
    - Assigning Different Value:-
      
      Multiple Values are assigned to the different variables in a single line
      ```python
      x,y = 10,'world'
      print(x,y)
      ```
      Output:-
      ```text
      10 world
      ```
