# String Functions in Python

String functions are built-in Python functions used to perform operations on strings.

Functions help to:

- Find length
- Find maximum/minimum character
- Sort characters
- Convert data types
- Check character values

---

## Common String Functions

| Function      | Purpose                        |
| ------------- | ------------------------------ |
| `len()`       | Returns length of string       |
| `max()`       | Returns largest character      |
| `min()`       | Returns smallest character     |
| `sorted()`    | Sorts characters               |
| `type()`      | Returns data type              |
| `str()`       | Converts value to string       |
| `ord()`       | Returns Unicode value          |
| `chr()`       | Returns character from Unicode |
| `enumerate()` | Returns index and character    |
| `any()`       | Checks if any value is True    |
| `all()`       | Checks if all values are True  |

---

### 1️⃣ `len()` Function :-

Returns the total number of characters in a string.

Syntax:

```python
len(string)
```

- Basic Example:

```python
text = "Python"

print(len(text)) #6
```

Explanation:

Python contains 6 characters.

- Example with Spaces

Spaces are also counted as characters.
``` python
text = "Python Programming"

print(len(text)) #18
``` 


Explanation:

"Python" → 6 characters
Space → 1 character
"Programming" → 11 characters

Total = 18

- Example with Numbers
``` python
text = "Python123"

print(len(text)) #9 
``` 
Explanation:

Numbers are counted as characters.

- Example with Special Characters
``` python
text = "Python@2025!"

print(len(text)) #12
``` 
Explanation:

Special symbols like @ and ! are also counted.

- Example with Empty String
``` python
text = ""

print(len(text)) #0
``` 
Explanation:

The string contains no characters.

---

### 2️⃣ `max()` Function :-

Returns the character with the highest ASCII/Unicode value.

Syntax:

```python
max(string)
```

Example:

```python
text = "Python"

print(max(text)) #y
```
Explanation:

y has the highest Unicode value among characters.

---

### 3️⃣ min() Function

Returns the smallest character.

Syntax:
```python
min(string)
```

Example:
```python
text = "Python"

print(min(text)) #P
```

---

### 4️⃣ sorted() Function

Sorts all characters alphabetically. sorted() works using ASCII/Unicode values.
The sorted() function returns a list, not a string.

Syntax:
```python
sorted(string)
```

Example:
```python
text = "python"

print(sorted(text)) #['h', 'n', 'o', 'p', 't', 'y']
```

Explanation:
Returns a list of sorted characters.

**ASCII SORTING ORDER**
| Order | Character Type     |
| ----- | ------------------ |
| 1     | Special characters |
| 2     | Numbers            |
| 3     | Uppercase letters  |
| 4     | Lowercase letters  |

---

### 5️⃣ type() Function

Returns the data type of the variable.

Syntax:
```python
type(variable)
```

Example:
```python
text = "Python"

print(type(text)) #<class 'str'>
```

---

### 6️⃣ str() Function

The str() function converts:
- Integers
- Float numbers
- Boolean values
- Lists
- Tuples
- Dictionaries
- Other objects

into string format.

Syntax:
```python
str(value)
```

Example:
```python
num = 100

print(str(num))        #100
print(type(str(num)))  #<class 'str'>
```

---

### 7️⃣ ord() Function

Returns Unicode (ASCII) value of a character.

Syntax:
```python
ord(character)
```

Example:
```python
print(ord('A')) #65
print(ord('a')) #97
```

---

### 8️⃣ chr() Function

Returns character for a Unicode value.

Syntax:
```python
chr(number)
```

Example:
```python
print(chr(65)) #A
print(chr(97)) #a
```

---

### 9️⃣ enumerate() Function

The enumerate() function is used to get:

- Index (position)
- Value (character)

together while looping through a string.

It is very useful when we need both the index and the character at the same time.

Syntax:
```python
enumerate(string)
```

Example:
```python
text = "Python"

for i, ch in enumerate(text):
    print(i, ch)
```

Output:
```
0 P
1 y
2 t
3 h
4 o
5 n
```

```python
# Custom Syntax
text = "Python"

for i, ch in enumerate(text, start=1):
    print(i, ch)
```
Output:
```
1 P
2 y
3 t
4 h
5 o
6 n
```

** Enumerate Object Type **
```python
text = "Python"

e = enumerate(text)

print(type(e)) #<class 'enumerate'>
```

### 🔟 any() Function

Returns True if at least one value is True.

Example:
```python
text = "Python"

print(any(text)) #True
```
Explanation:

Since the string is not empty, result is True.

---

### 1️⃣1️⃣ all() Function

The all() function checks whether all characters/values in a string satisfy a condition.

Example:
```python
text = "Python"

print(all(text)) #True
```
```
all() returns True for empty iterables because:

"There is no False value present."

This is called vacuous truth.
```
