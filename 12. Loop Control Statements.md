In Python, loop control statements change the normal flow of a loop. They allow you to stop, skip, or control execution inside loops like for and while.

There are three main loop control statements:

1. break

2. continue

3. pass

---

## 1️⃣ `break` Statement
The break statement immediately terminates the loop, even if the loop condition is still true.

When break executes, the program exits the loop and continues with the next statement after the loop.

Syntax:
```python
for variable in sequence:
    if condition:
        break
```

Example 1: Using break in a for loop
```python
for i in range(1, 10):
    if i == 5:
        break
    print(i)
```
Output:
```text
1
2
3
4
```

Example 2: Using break in a while loop
```python
i = 1

while i <= 10:
    if i == 6:
        break
    print(i)
    i += 1
```

Output:
```text
1
2
3
4
5
```

---

## 2️⃣ continue Statement

The continue statement skips the current iteration and moves to the next iteration of the loop.

The loop does not stop, it just skips one cycle.

Syntax:
```python
for variable in sequence:
    if condition:
        continue
```

Example 1:
```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

Output
```text
1
2
4
5
```

---

## 3️⃣ pass Statement

The pass statement does nothing.
It is used as a placeholder when a statement is required but no code needs to run.

Syntax:
```python
for variable in sequence:
    pass
```
