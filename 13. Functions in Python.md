Python functions are reusable blocks of code designed to perform a specific task. They help make programs cleaner, modular, and easier to debug.

## 🔹 Defining a function

You define a function using the def keyword
``` python
def greet():
    print("Hello, World!")
```

### Calling the function:
``` python
greet()
```

Output:-
```
Hello, World!
```

## 🔹 Function with Parameters

Functions can take inputs (parameters):
``` python
def greet(name):
  print(f"Hello, {name}")
greet('Sahana')
```
Output:-
```
Hello, Sahana
```

## 🔹 Function with Return Value

Functions can return results using return:

``` python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)
```
Output:-
```
7
```

## 🔹 Default Parameters

You can provide default values:
``` python
def greet(name="Guest"):
    print("Hello,", name)

greet()         # Hello, Guest
greet("John")   # Hello, John
```

## 🔹 Keyword Arguments

You can pass arguments by name:
```python
def student(name, age):
    print(name, age)

student(age=20, name="Ravi")
```

## 🔹 Arbitrary Arguments
*args (multiple positional arguments)
``` python
def total(*numbers):
    return sum(numbers)

print(total(1, 2, 3, 4)) # 10
```
*numbers collects all positional arguments into a tuple

total(1, 2, 3, 4) becomes: numbers = (1, 2, 3, 4)

If you pass different values, it will just sum all of them:

total(5, 10)        # 15
total(1, 2, 3, 4, 5)  # 15

**kwargs (multiple keyword arguments)
```text
def details(**info):
    print(info)

details(name="Ravi", age=20)
```
**info gathers all keyword arguments into a dictionary

details(name="Ravi", age=20) becomes: info = {'name': 'Ravi', 'age': 20}

Output:
```text
{'name': 'Ravi', 'age': 20}
```
