# Comments
- Comments in Python start with the hash character, #, and extend to the end of the physical line.
  
  ```python
  #This is our first comment
  ```
  
- A comment may appear at the start of a line or following whitespace or code.
  
  ```python
  print("Second Comment") # This is our second comment
                          # This is our third comment
  ```
  
- A Comment cannot appear within a string literal.
  
  ```python
  print("#This is not considered as a comment")
  ```
