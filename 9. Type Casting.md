# Type Casting in Python

Type Casting means converting one data type into another data type

### Why Type Casting is needed?
- To perform operations between data types
- To take user input ( Since input is always a string )
- To control data type of result

Example:-
```python
a = "10"
b = 5
print(a + b)   # ❌ Error
```

### Types of Type Casting

Python supports two types

1) Implicit Type Casting
2) Explicit Type Casting

---

- Implicit Type Casting (Automatic):-

Python automatically converts smaller type to larger type
``` python
a = 5        # int
b = 2.5      # float
c = a + b
print(c)
print(type(c))
```
Output:-

```text
7.5
<class 'float'>
```

---

- Explicit Type Casting ( Manual ):-

Programmer manually converts data type using built-in Functions

| Function  | Converts To | Example                       |
| --------- | ----------- | ----------------------------- |
| `int()`   | Integer     | `int(5.8)` → 5                |
| `float()` | Float       | `float(10)` → 10.0            |
| `str()`   | String      | `str(25)` → "25"              |
| `bool()`  | Boolean     | `bool(0)` → False             |
| `list()`  | List        | `list("abc")` → ['a','b','c'] |
| `tuple()` | Tuple       | `tuple([1,2])` → (1,2)        |
| `set()`   | Set         | `set([1,1,2])` → {1,2}        |

Examples of Explicit Type Casting

Integer Casting:-

``` python
print(int(10.7))    # 10
print(int("25"))    # 25
```

⚠️ Invalid:
```python
int("10.5")   # Error
```

Float Casting:-
``` python
print(float(10))       # 10.0
print(float("5.6"))    # 5.6
```

String Casting:-
```python
a = 100
print("Value is " + str(a))
```

Boolean Casting:-
| Value                | bool(value) |
| -------------------- | ----------- |
| `0`, `None`, `""`    | False       |
| Non-zero / Non-empty | True        |

```python
print(bool(0))     # False
print(bool(10))    # True
print(bool(""))    # False
```

Type Casting with input():-

```python
age = int(input("Enter age: "))
print(age + 1)
```
input() always returns string, so casting is required.

## 🧠 Common Mistakes

1) The below example causes `ValueError`
   ```python
   int("abc")
   ```
2) Observe the below example
   ```python
   int("10.5") # Error
   ```
   Convert to float first:
   ``` python
   int(float("10.5"))
   ```
