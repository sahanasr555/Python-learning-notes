## Indentation

- In Python, Indentation is used to define a block of code

- All statements with the same level of indentation are treated as part of the same code block.
  
- Indentation is created using whitespace at the beginning of each line, and the commonly accepted convention is to use four spaces per indentation level.
```python
print("I have no Indentation ")
    print("I have tab Indentation ")
```
Output:-
```text
ERROR!
Traceback (most recent call last):
  File "<main.py>", line 2
    print("I have tab Indentation ")
IndentationError: unexpected indent
```
The second print statement has tab indentation, but it doesn't belong to a new block of code. Python expects the indentation level to be consistent within the same block. This inconsistency causes an IndentationError.
