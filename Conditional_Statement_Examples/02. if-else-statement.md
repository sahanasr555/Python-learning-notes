## 1. Write a program to check if a number is even or odd.

Program 1:-
```python
number = float(input("Enter the number: "))

if number.is_integer():
    number = int(number)
    if number % 2 == 0:
        print(f"{number} is Even")
    else:
        print(f"{number} is Odd")
else:
    print("Even/Odd is defined only for integers.")
```

Program 2:-
```python
number = float(input("Enter the number: "))

if number.is_integer():
    number = int(number)
    if (number // 2) * 2 == number:
        print(f"{number} is Even")
    else:
        print(f"{number} is Odd")
else:
    print("Even/Odd is defined only for integers.")
```

Output:-
```text
Enter the number:  9.8
Even/Odd is defined only for integers.
```
```text
Enter the number:  100
100 is Even
```
```text
Enter the number:  -35
-35 is Odd
```
